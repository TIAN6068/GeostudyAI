# GeoStudy AI · WebGIS 与三维可视化开发（课程学习平台）

> 高校 GIS 专业课程 AI 学习平台 Demo。围绕一门真实专业课程，把「学情诊断 → 个人课程路线 → AI 课程导师 → 成果检测 → 能力评价 → 成长档案」连接成一个可持续、可验证、可改造的学习闭环。
>
> **定位：模板 / 示例资源。** 所有文案与评分均为示例数据，改 `config.js` 即可把它变成你自己的课程，无需改动渲染逻辑。

## 二、技术栈

- 纯静态前端：**HTML + CSS + 原生 JavaScript（无框架、无打包、无 npm install）**
- 可视化：`Canvas 2D`（默认自转地球）+ `CesiumJS`（可选三维地球，CDN 引入）
- 数据：单一 `config.js` 配置对象，渲染引擎 `main.js` 读取后输出
- 持久化：`localStorage`（学习记录、课程路线生成状态，全程 try/catch）

## 三、运行方式

### 方式 A：直接打开（最简单）
双击 `index.html` 即可在浏览器运行。Cesium 三维地球需联网加载 CDN；**离线时自动降级为本地 Canvas 地球**，功能不受影响。

### 方式 B：本地静态服务器（推荐，避免个别浏览器对 `file://` 的限制）
```bash
# 任选其一，在项目根目录执行
python -m http.server 8080
# 或
npx serve .
```
然后访问 `http://localhost:8080`。

## 五、如何改造成你自己的课程（核心卖点：可复用）

**只改 `config.js`，不要改 `main.js`。** 常见改造点：

1. **换课程**：改 `meta.course` 相关与 `task.courseCard.course`。
2. **换任务包**：改 `task.stages`，每个阶段可写 `tasks / tools / artifact / experience（实操经验）/ pitfalls（避坑指南）/ expansions（拓展知识点）`。
3. **换导师知识**：改 `mentor.topics` 与 `mentor.keywordMap`（决定不同问题命中不同诊断）。
4. **换集市资源 / 档案 / 评价**：分别对应 `market` / `archive` / `evaluation`。
5. **去个人化**：`meta.learner` 与 `archive.profile` 中的姓名、学号均为示例，替换为真实学员即可。

改完刷新页面即生效，无需任何构建步骤。

## 六、任务包「优化版」包含什么

以 12 周《WebGIS与三维可视化开发》为例，每个阶段在原生任务清单基础上，额外沉淀：

- **◆ 实操经验**：来自真实学习过程的可迁移做法（如「拿数据先问坐标系/精度/来源」）。
- **⚠ 避坑指南**：高频错误与原因（如经纬度顺序写反、GCJ-02 叠加偏移、3D Tiles transform 重复平移）。
- **✦ 拓展知识点**：延伸学习路径（如 OGC 标准、CGCS2000 与 WGS84 差异、3D Tiles 1.1）。
- 一键 **导出 JSON / Markdown**，作为可复用的课程任务包交付物。

## 七、AI 边界与合规（已在「产品与数据说明」页呈现）

- AI 课程导师与成果评价为**演示规则引擎**，不伪称已接入远程大模型；部署版可通过服务器安全接入。
- 前端**不收集**身份证、精确定位、人脸等敏感信息；上传仅在本机读取文件名与大小。
- 评价用于**形成性学习反馈**，不替代教师最终评分；空间精度、代码安全由教师复核。
- 数据来源可追溯、许可明确、隐私脱敏、AI 生成内容标识。

## 九、已知限制

- 导师对话**默认是关键字路由的本地知识库回答**（离线可用、零密钥）；现已支持经本地代理 `mentor-proxy.js` 安全接入 DeepSeek 实时模型（见「十、启用实时 AI」），前端不持有任何密钥，接口异常时自动回退本地回答。
- Cesium 三维地球依赖 CDN，离线时由 Canvas 地球兜底（视觉降级，功能不降级）。
- 成果检测为**前端结构校验演示**，真实代码沙箱/空间规范检查需后端服务支撑。

## 十、启用实时 AI 课程导师（DeepSeek，可选）

默认课程导师是「关键字路由的本地知识库」回答（离线可用、零密钥）。如需接入真实大模型，提供了一条**安全路径**：用一个零依赖的本地 Node 代理持有密钥并转发，浏览器不直接持有任何密钥，也规避了 DeepSeek 的浏览器 CORS 限制。

**1. 启动代理（代理内置你的 DeepSeek Key，也可改用环境变量）**
```bash
node mentor-proxy.js
# 或自定义端口 / 密钥：
PORT=8787 DEEPSEEK_API_KEY=sk-xxxx node mentor-proxy.js
```
代理监听 `http://localhost:8787/api/deepseek`。

**2. 前端已默认指向该代理**（`config.js` 的 `mentor.deepseek`）：
```js
deepseek: {
  enabled: true,
  proxyUrl: "http://localhost:8787/api/deepseek",
  model: "deepseek-v4-flash",
  direct: false
}
```

**3. 行为**
- 学生发问 → 优先调用 DeepSeek（携带课程上下文系统提示）→ 实时回答渲染到对话区。
- 代理不可用 / 网络异常 / 密钥失效 → 自动回退到本地课程知识库回答，并提示「实时 AI 暂不可用，已切换为本地知识库回答」，页面不白屏。

**安全说明**：密钥只存在于 `mentor-proxy.js`（服务端）。如要公开发布或上架，请改为环境变量 `DEEPSEEK_API_KEY` 并轮换密钥，切勿把密钥写进前端代码（否则任何人都能从页面源码提取并盗刷）。
